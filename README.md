# Exposición: Patrones GRASP

Este proyecto consiste en una página web de exposición sobre el tema **Patrones GRASP**, desarrollada por los alumnos del **Grupo Nº7** de la **Universidad Tecnológica Nacional – Facultad Regional Tucumán**, para la **Cátedra de Diseño de Sistemas**.

La página presenta una **introducción general** al concepto de GRASP y el desarrollo de **cinco patrones específicos**, organizados en secciones.

---

## 📚 ¿Qué son los patrones GRASP?

GRASP (_General Responsibility Assignment Software Patterns_) es un conjunto de principios de diseño orientados a objetos, propuestos por **Craig Larman**, que ayudan a asignar responsabilidades de manera adecuada en un sistema.

Los patrones permiten resolver problemas comunes en el diseño de software, mejorando la **flexibilidad, mantenibilidad y claridad** del código.

---

## 📂 Contenido de la página

La exposición está organizada en secciones, cada una dedicada a un patrón GRASP:

1. **Controlador**
2. **Polimorfismo**
3. **Fabricación Pura**
4. **Indirección**
5. **Variaciones Protegidas**

Cada sección incluye:

- **El problema a resolver**

  - Situaciones conflictivas en el software.
  - Analogía con un caso de la vida real.

- **El patrón como solución**

  - Definición técnica.
  - Explicación con analogía, manteniendo la comparación con la vida real.

- **Tipos o variantes** (si las hubiera)

  - Descripción de cada tipo.
  - Características y momentos de uso.

- **Ejemplos**

  - Un ejemplo cotidiano (no técnico).
  - Un ejemplo aplicado en software:
    - Código en un lenguaje simple (ej. Java o C#).
    - Diagrama UML con breve descripción.

- **Pros y Contras**

  - Beneficios de aplicar el patrón.
  - Posibles desventajas o antipatrones.
  - Remedios o soluciones a estas limitaciones.

- **Fuentes**
  - Bibliografía y material consultado.
